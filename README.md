# Test unitaire pour débutant
  
## Initialisation du projet
Création du dossier `test-unitaire-debutant` et initialisation d'un projet Node.js avec la commande `npm init -y`. Cette commande génère automatiquement un fichier `package.json`
qui contient la configuration du projet.

![Initialisation du projet]
![img package.json](<images/Capture d’écran du 2026-06-08 10-55-51.png>)

## Installation de Jest
Installation de Jest en tant que dépendance de développement avec la commande `npm install --save-dev jest`. Jest est le framework de tests unitaires qu'on va utiliser pour tester
nos fonctions JavaScript.

![Installation de Jest]
![img jest](<images/Capture d’écran du 2026-06-08 10-48-02.png>)
